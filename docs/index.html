Verified

Original menus and languages

v5.79 and v6.39 have booted on the FPGA. Phonebook, Settings, language selection and applying Russian are confirmed by HDMI captures.

In progress

Boot and virtual SIM

Repeated boots are not yet reliable. The SIM model needs more work; sustained operation and games have not been verified.

In progress

Physical controller

DS2 communication and key mapping pass RTL tests. The connected controller does not yet operate the phone; hardware debugging is underway.

Limitation

Cellular connectivity

A GSM radio is not implemented. The project cannot make cellular calls or send SMS over a mobile network.

OPEN-SOURCE TOOLCHAIN

From source
to FPGA.

Yosys + Slang, nextpnr, Apicula and Verilator. RTL sources, tests and tools are included in the repository.

  1. Install Python 3, OSS CAD Suite and g++ with C++20 support.
  2. Run the RTL tests and build nokia_top.
  3. Prepare your own ROM dump. Proprietary firmware is not included in this repository.
  4. Back up SPI flash before writing the ROM at offset 0x200000.
Full instructions ↗
git clone https://github.com/LakoMoor/OpenNokia3310
cd OpenNokia3310
python tools/test.py
python tools/build.py nokia_top

# Load FPGA configuration into SRAM
openFPGALoader -b tangnano20k \
  build/nokia_top_lut4/nokia_top.fs

Writing settings from SDRAM back to SPI flash is not implemented yet. Language changes are lost after a restart.
